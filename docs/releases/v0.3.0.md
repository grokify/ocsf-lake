# Release Notes v0.3.0

**Release Date:** November 6, 2026

## Overview

This release moves the module to the OpenSecurity Institute organization at
`github.com/opensecurity-dev/ocsf-lake`, and moves its OCSF dependency to
`github.com/opensecurity-dev/ocsf-schema-go`. The storage, validation,
record-integrity and CLI behavior are unchanged.

## Installation

### Library

```bash
go get github.com/opensecurity-dev/ocsf-lake@v0.3.0
```

### CLI

```bash
go install github.com/opensecurity-dev/ocsf-lake/cmd/ocsflake@v0.3.0
```

## Breaking Changes

### Module path

The module moved from `github.com/grokify/ocsf-lake` to
`github.com/opensecurity-dev/ocsf-lake`. Versions up to v0.2.0 stay available at
the old path; new versions are published only at the new one.

The OCSF types the lake's API exposes now come from
`github.com/opensecurity-dev/ocsf-schema-go` v0.3.0, so code that passes
ocsf-schema-go types to the lake must import them from the new path as well.
Replace both paths and run `go mod tidy`:

```bash
grep -rlE 'github.com/grokify/ocsf-(lake|schema-go)' --include='*.go' . |
  xargs sed -i.bak -E 's#github.com/grokify/ocsf-(lake|schema-go)#github.com/opensecurity-dev/ocsf-\1#g'
go mod tidy
```
