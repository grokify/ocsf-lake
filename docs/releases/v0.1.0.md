# Release Notes v0.1.0

**Release Date:** June 29, 2026

## Overview

This is the initial release of ocsf-lake, a Go library for storing, validating, and
querying [OCSF](https://ocsf.io/) (Open Cybersecurity Schema Framework) events with
pluggable storage backends.

Events are ingested as raw OCSF JSON. The lake extracts the key classification, time,
and source fields into indexed columns, keeps the full payload alongside them, and
exposes a query builder and convenience queries over the result.

## Installation

```bash
go get github.com/grokify/ocsf-lake@v0.1.0
```

SQLite support requires CGO and the SQLite driver:

```bash
go get github.com/mattn/go-sqlite3
```

## Highlights

- Ent-backed storage on SQLite (in-memory or file) and PostgreSQL
- Ingest, query, count, and delete through a single `Lake` facade
- Strict, permissive, and disabled validation modes
- Go constants for OCSF categories, classes, severities, and statuses

## Features

### Lake facade (`pkg/lake`)

- `lake.New(ctx, opts...)` with `WithSQLiteMemory`, `WithSQLiteFile`, and `WithPostgres`
- `Ingest` (single or batch) and `IngestWithID`
- `Get`, `Query`, `Count`, `Delete`, and `Close`
- Convenience queries: `QueryByClassUID`, `QueryByCategoryUID`, `QueryBySeverityID`,
  `QueryBySource`, and `QueryByTimeRange`
- `Storage()` exposes the underlying backend for advanced use

### Storage (`pkg/storage`, `ent/`)

The `Storage` interface covers `Insert`, `Get`, `Query`, `Count`, `Delete`, and `Close`,
implemented on Ent. Each event is stored with its payload and indexed columns:

- `class_uid`, `category_uid`, `activity_id`, `type_uid`
- `severity_id`, `status_id`
- `time` and `ingested_at`
- `source` and `schema_version`
- optional `raw_data`

Composite indexes pair `class_uid`, `category_uid`, `type_uid`, and `source` with `time`.

### Query builder

A fluent builder supports filtering by class, category, type, activity, severity,
status, and source, plus time range, limit, offset, and ordering by event time or
ingestion time.

```go
q := l.QueryBuilder().
    WithCategoryUID(ocsf.CategoryUIDIAMActivity).
    WithSeverityID(ocsf.SeverityIDHigh).
    WithTimeRange(from, to).
    WithLimit(100).
    OrderByTime(true).
    Build()

events, err := l.Query(ctx, q)
```

### Validation (`pkg/validator`)

- **Strict** (default): rejects events that fail validation
- **Permissive**: tolerates non-critical issues
- **Disabled**: skips validation

### OCSF types (`pkg/ocsf`)

Hand-written Go types for the base OCSF event and `StoredEvent`, along with constants
for categories, classes, severities, and statuses.

## Known Limitations

- OCSF types and constants are hand-maintained and cover only a subset of the standard
- Validation is JSON Schema based and checks a limited set of attributes
- No record-integrity (signing, verification, or chaining) support
- No command-line interface

These are addressed in [v0.2.0](v0.2.0.md), which moves the OCSF types and validation
onto `ocsf-schema-go` and adds record integrity and the `ocsflake` CLI.
