    Lake API¶

    The Lake type is the main facade for storing and querying OCSF events.

    Package¶

    import "github.com/grokify/ocsf-lake/pkg/lake"

    Creating a Lake¶

    New¶

    func New(ctx context.Context, opts ...Option) (*Lake, error)

    Creates a new Lake with the given options.

    Example:

    l, err := lake.New(ctx,
    lake.WithSQLiteMemory(),
    lake.WithStrictValidation(),
)
if err != nil {
    log.Fatal(err)
}
defer l.Close()

    Configuration Options¶

    WithSQLiteMemory¶

    func WithSQLiteMemory() Option

    Configures the Lake to use in-memory SQLite. Data is lost when the process exits.

    WithSQLiteFile¶

    func WithSQLiteFile(path string) Option

    Configures the Lake to use file-based SQLite.

    WithPostgres¶

    func WithPostgres(connStr string) Option

    Configures the Lake to use PostgreSQL.

    Connection string format:

    postgres://user:password@host:port/database?sslmode=disable

    WithStrictValidation¶

    func WithStrictValidation() Option

    Rejects events with any schema violation (missing required attributes, wrong types, invalid enums, violated constraints, inconsistent UIDs). This is the default mode.

    WithPermissiveValidation¶

    func WithPermissiveValidation() Option

    Rejects only structurally unusable events (malformed JSON, missing or unknown class_uid); other schema violations are tolerated.

    WithNoValidation¶

    func WithNoValidation() Option

    Skips validation entirely.

    WithSchemaVersion¶

    func WithSchemaVersion(version string) Option

    Sets the OCSF schema version recorded on stored events. Defaults to events.SchemaVersion from ocsf-schema-go (the version the bindings were generated from).

    WithDefaultSource¶

    func WithDefaultSource(source string) Option

    Sets the default source for events that don't specify one.

    WithUnknownAttributes¶

    func WithUnknownAttributes(m validate.UnknownMode) Option

    Controls how attributes absent from the OCSF schema are treated during validation: validate.UnknownWarn (default), validate.UnknownIgnore, or validate.UnknownError (strict mode then rejects them).

    WithRawDataRetention¶

    func WithRawDataRetention() Option

    Stores each event's original JSON bytes as received (before any lake attestation) in StoredEvent.RawData, preserving forensic evidence at the cost of roughly doubling per-event storage.

    WithIngestIntegrity¶

    func WithIngestIntegrity(mode IngestIntegrityMode, policy integrity.Policy) Option

    Verifies producer record_integrity attestations during ingestion. IngestIntegrityMonitor stamps integrity_status on stored events without rejecting; IngestIntegrityEnforce rejects failing events with *IntegrityRejectionError. See Integrity.

    WithIngestAttestation¶

    func WithIngestAttestation(a AttestationOptions) Option

    Makes the lake sign every ingested event with its own attestation, optionally chaining events tamper-evidently (ChainUID). The chain tail is process-local; persist Lake.ChainTail() and pass it back as InitialChainTail to continue a chain across restarts.

    Methods¶

    Ingest¶

    func (l *Lake) Ingest(ctx context.Context, events ...json.RawMessage) error

    Validates and stores one or more OCSF events.

    Example:

    event := json.RawMessage(`{
    "class_uid": 3002,
    "category_uid": 3,
    "activity_id": 1,
    "type_uid": 300201,
    "time": 1704067200000
}`)

err := l.Ingest(ctx, event)

    IngestWithID¶

    func (l *Lake) IngestWithID(ctx context.Context, id string, event json.RawMessage) error

    Ingests an event with a specific ID (instead of auto-generating one).

    IngestTyped¶

    func (l *Lake) IngestTyped(ctx context.Context, events ...any) error

    Ingests typed events, such as the generated structs from github.com/grokify/ocsf-schema-go/ocsf/events (e.g. events.Authentication), through the same validation and indexing pipeline as Ingest.

    Get¶

    func (l *Lake) Get(ctx context.Context, id string) (*ocsf.StoredEvent, error)

    Retrieves a single event by ID.

    Query¶

    func (l *Lake) Query(ctx context.Context, q *storage.Query) ([]*ocsf.StoredEvent, error)

    Retrieves events matching the query parameters.

    QueryBuilder¶

    func (l *Lake) QueryBuilder() *storage.QueryBuilder

    Returns a new query builder for constructing queries.

    Count¶

    func (l *Lake) Count(ctx context.Context, q *storage.Query) (int, error)

    Returns the number of events matching the query.

    Delete¶

    func (l *Lake) Delete(ctx context.Context, q *storage.Query) (int, error)

    Removes events matching the query. Returns the number of deleted events.

    Close¶

    func (l *Lake) Close() error

    Closes the Lake and releases resources.

    Integrity Methods¶

    IntegrityChecker¶

    func (l *Lake) IntegrityChecker(policy integrity.Policy) *integrity.Checker

    Returns a record-integrity checker over this lake's storage. See Integrity for check modes.

    IntegrityReports¶

    func (l *Lake) IntegrityReports(ctx context.Context, kind string, limit int) ([]*ocsf.IntegrityCheckRecord, error)

    Returns persisted check runs, newest first, optionally filtered by kind (event, all, incremental, sample, chain).

    ChainTail¶

    func (l *Lake) ChainTail() []byte

    The last attested event JSON when attest-on-ingest chaining is enabled; persist it to continue the chain across restarts.

    Errors¶

    var (
    ErrInvalidBackend = errors.New("invalid storage backend configuration")
    ErrClosed         = errors.New("lake is closed")
)

    IntegrityRejectionError is returned by ingestion when IngestIntegrityEnforce rejects an event; it carries the failing integrity.EventResult.
