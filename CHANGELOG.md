## [v0.2.0] - 2026-10-13 ([`2c23bb9`](https://github.com/grokify/ocsf-lake/commit/2c23bb9))

### Highlights

- OCSF types, constants, and validation now come from `github.com/grokify/ocsf-schema-go`; the lake no longer carries a hand-written copy of the standard
- Record-integrity support end to end: verify-on-ingest, attest-on-ingest with chaining, on-demand/full/incremental/sample/chain checks, and persisted check reports
- New `ocsflake` CLI covering ingest, query, integrity checks, signing, verification, and test-data seeding

### Added

- [validator] `OCSFValidator` backed by the compiled OCSF schema embedded in ocsf-schema-go, with strict, permissive, and disabled modes and no schema files needed at runtime ([`8b4a2f5`](https://github.com/grokify/ocsf-lake/commit/8b4a2f5))
- [ocsf] `StoredEvent.Decode()` returns the concrete generated event struct for a stored payload via the class-UID registry ([`da17603`](https://github.com/grokify/ocsf-lake/commit/da17603))
- [integrity] Record-integrity checker with on-demand, full, incremental, sample, and chain modes and an unsigned-events policy ([`69f39f9`](https://github.com/grokify/ocsf-lake/commit/69f39f9))
- [storage] `integrity_status` and `integrity_checked_at` event columns, a persisted `IntegrityCheck` entity, and `IngestedFrom` / `IntegrityStatus` query filters ([`808c79d`](https://github.com/grokify/ocsf-lake/commit/808c79d))
- [lake] Typed ingest (`IngestTyped`), verify-on-ingest (monitor/enforce), attest-on-ingest with optional chaining, raw-data retention, and an unknown-attribute policy ([`854cbc3`](https://github.com/grokify/ocsf-lake/commit/854cbc3))
- [seed] Deterministic schema-valid test-data generator with signed, tampered, and chained event mixes ([`cd3e6a5`](https://github.com/grokify/ocsf-lake/commit/cd3e6a5))
- [cmd/ocsflake] CLI with `ingest`, `get`, `query`, `count`, `check` (event, all, incremental, sample, chain, reports), `sign`, `verify`, and `seed` commands ([`9d53d63`](https://github.com/grokify/ocsf-lake/commit/9d53d63))

### Changed

- **BREAKING:** [ocsf] Hand-written `Event`, `ParseEvent`, and classification/metadata constants removed in favour of `ocsf-schema-go/ocsf/events` and `ocsf/objects` ([`da17603`](https://github.com/grokify/ocsf-lake/commit/da17603))
- **BREAKING:** [validator] JSON Schema validator, `validator.Options`/`DefaultOptions`, and the `ErrMissing*` sentinel errors removed; strict mode now enforces full schema semantics and permissive mode rejects only structurally unusable events ([`8b4a2f5`](https://github.com/grokify/ocsf-lake/commit/8b4a2f5))
- [lake] `Close` is idempotent and concurrency-safe, and batch ingest errors report the failing event position ([`854cbc3`](https://github.com/grokify/ocsf-lake/commit/854cbc3))
